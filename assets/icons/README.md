# Magnific toolbar icon assets

VideoAtlas supports **licensed PNG icons downloaded from https://www.magnific.com/icons**.

Place the PNG files in this folder using the toolbar label converted to lowercase
with spaces replaced by hyphens. For example:

- add-folder.png
- rescan.png
- stop-scan.png
- scenes.png
- timeline.png
- gallery.png
- contact-sheet.png
- sha-256.png
- duplicates.png
- find-duplicates.png
- transcribe.png
- ocr-frame.png
- ai-search.png
- visual-search.png
- add-collection.png
- view-collection.png
- queue-batch.png
- run-jobs.png
- stop-batch.png
- queue-status.png
- possible-dupes.png
- move-files.png
- backup.png
- export.png
- validate.png
- restore.png
- db-health.png
- dupe-details.png
- offline-status.png
- ai-models.png

Recommended format: transparent PNG, 64x64 pixels or larger, consistent icon
family and style. VideoAtlas displays them at 18x18 and falls back to built-in
Qt icons for missing files.

**Licensing:** Download only assets you have permission to use. Magnific's
free assets generally require attribution to the author; Premium licenses may
allow use without attribution. Keep the author and license details alongside
each asset, and include any required credits in the application or distribution.
This folder intentionally contains no third-party copyrighted images.
